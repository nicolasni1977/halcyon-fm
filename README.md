# Halcyon

A browser-based, hyper-realistic recreation of the Apple iPod classic (7th gen). Single self-contained `index.html` — no build step, no dependencies, runs offline once loaded.

The hardware shell, click wheel, and on-screen menus are all rendered in CSS + SVG. The click and button sounds are synthesized at runtime via the Web Audio API — no audio asset files ship with the UI.

## What works

| Area | Detail |
|---|---|
| **Click Wheel** | Pointer-angle math (`atan2`), one tick every ~12° = ~30 ticks per revolution. Touch + mouse parity via pointer events. Tap any of the 4 sectors (Menu / Prev / Next / Play-Pause) or the center button. Hold center 600ms for the context popover; hold play/pause 1500ms to power off. |
| **Boot** | Serif "Halcyon" wordmark fades in over 600ms, holds 800ms, fades out — then the main menu. Power-on sweep 200→1200Hz; power-off 1200→200Hz. |
| **Main menu** | Music · Videos · Photos · Podcasts · Extras · Settings · Shuffle Songs · Now Playing |
| **Music submenu** (10 items, manual order) | Cover Flow · Playlists (with On-The-Go nested) · Artists · Albums · Songs · Genres · Composers · Audiobooks · Compilations · Search |
| **Extras submenu** | Alarms · Calendars · Clocks · Contacts · Games · Notes · Screen Lock · Stopwatch · Voice Memos |
| **Settings** (12 cases) | About · Shuffle · Repeat · Audiobooks (speed) · EQ (13 presets) · Sound Check · Volume Limit · Clicker · Backlight Timer · Brightness · Language · Reset Settings |
| **Now Playing** | Cinematic full-bleed album art with title/artist/album overlaid in serif text. Scrubber bar with elapsed/remaining. Center cycles modes: default → scrubber → rating → shuffle → repeat. Hold-center: Browse Artist / Browse Album / Add to On-The-Go / Start Genius. |
| **Library** | Drag-and-drop a folder of MP3s onto the page → ID3v2 tags parsed, cover art extracted, blobs stored in IndexedDB, metadata in localStorage. Persists across reloads. |
| **Procedural sounds** | Wheel tick (8ms noise + 2.2kHz highpass), button tock (12ms with lowpass), select-confirm (tock + 800Hz pip), power-on/off sweeps. All Web Audio — zero audio files. |
| **Hold switch** | Toggles a lock state that disables all input. Orange bar appears on the switch; lock icon replaces the iPod title in the status bar. |
| **Backlight timer** | Screen dims to ~30% after idle. First input wakes without firing the action (per-gesture `_consumedByWake` flag). |
| **Mobile** | Full pointer/touch parity. Scales to portrait phones (`viewport-fit=cover`, safe-area insets). First wheel tap unlocks iOS AudioContext. |
| **Keyboard fallback** | ↑/↓ scroll · Enter = center · Backspace = Menu · Space = Play/Pause · ←/→ = Prev/Next · `?` shows the keymap overlay. |

## Tested

`navigation-smoke-test.js` (Playwright) drives the full menu graph end-to-end:

- 8 main-menu entries → enter every submenu → Menu-back returns to the main menu
- 10 Music submenu items invoked, none throw
- 12 Settings items: every cyclable value advances correctly; About opens an info screen; Menu dismisses it
- 9 Extras items each render their info card

49 / 49 checks pass in headless Chromium.

## How it was built

Generated by a hybrid multi-agent pipeline (Orchestrator → Planner → Generator → Verifier) running on Claude Sonnet 4.6 + claude.ai-subscription verifier. The behavioral spec lives at `plan/halcyon-plan.md` in the parent project; the click-wheel math, sound recipes, state machine, and unit-test names are all spelled out there.

This is Take 3 — refined for an exact visual match to the silver iPod classic (7th gen) photograph: matte silver body with subtle vertical brushing, glossy white click wheel with proper MENU / skip-back / skip-forward / play-pause glyphs, recessed plain center button, and a split-pane menu screen showing album art preview alongside the menu list.

## Run locally

```bash
# Just open index.html in a browser
xdg-open index.html        # Linux
open index.html            # macOS
start index.html           # Windows
```

A few things only work over HTTP(S) (not `file://`):
- Fetching the demo MP3s from `assets/music/` (CORS / file-scheme restriction)
- Service-worker offline caching (not enabled here)

Drag-and-drop ingest works everywhere.

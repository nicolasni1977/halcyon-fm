Generator directives

  • Generate the COMPLETE single index.html file. No placeholder comments like '// TODO implement'. Every feature must be fully implemented.
  • CRITICAL VISUAL REQUIREMENT: The iPod body must use at minimum 3 layered CSS gradients to achieve the brushed aluminum look. Do NOT use a flat silver color. Use: (1) base radial gradient center-bright to edge-dark, (2) vertical repeating-linear-gradient with 1px stripes at 2% opacity for grain, (3) a linear gradient top-to-bottom for lighting.
  • CRITICAL VISUAL REQUIREMENT: The click wheel MUST be a true donut/ring shape. Use one of: (a) CSS clip-path with polygon cutout, (b) SVG with a circle and inner circle subtracted, or (c) a positioned outer circle with a matching inner circle overlay. The center button is a SEPARATE element on top, not part of the ring.
  • CRITICAL VISUAL REQUIREMENT: The split-pane layout with status bar, left menu list (8 items), and right album art pane must be pixel-precise as described. The blue selection gradient must span the full pane width with white text and '>' chevron. This is the most photographed screen of the reference.
  • CRITICAL BEHAVIORAL REQUIREMENT: The WheelEngine pointer event handling must use setPointerCapture on pointerdown so drag continues outside the wheel element. Angular delta accumulates across the full drag; only emit ticks when threshold crossed, NOT on every mousemove.
  • CRITICAL BEHAVIORAL REQUIREMENT: Implement the _consumedByWake pattern exactly: in pointerdown handler, if backlightDim===true, set _consumedByWake=true, wake backlight, and return (do NOT process the event further). In pointerup, check _consumedByWake at the TOP before any sector dispatch, clear it, and return.
  • Generate the ID3 parser inline without any npm/CDN imports. The parser must correctly read 'ID3' magic bytes, parse tag size (syncsafe integer), iterate frames, decode TIT2/TPE1/TALB/TRCK text frames with encoding byte, and extract APIC binary data.
  • Generate the procedural mosaic SVG: create a 4×4 or 5×5 grid of rectangles, each with a color from a deterministic palette derived from the seed (use simple LCG RNG). Include diagonal gradient overlays on some cells. Output as a data URL for use as background-image.
  • Generate all Web Audio sounds as described — do NOT use any external audio files for UI sounds. Noise buffers should be pre-generated once at AudioContext init and stored in module scope.
  • Generate Cover Flow with full CSS 3D transforms. The 3D carousel container must have: transform-style: preserve-3d; perspective: 800px. Each album card transitions smoothly between positions on wheel scroll.
  • The context menu popover (long-press center) must render as an overlay within the screen with 4 options: 'Browse Artist', 'Browse Album', 'Add to On-The-Go', 'Start Genius'. Must be dismissible with MENU button.
  • Generate the '?' keyboard shortcuts overlay as a full-screen (or screen-sized) dark semi-transparent overlay listing all shortcuts in a clean two-column layout.
  • Ensure the device scales correctly on mobile: the entire iPod transform: scale() approach means the device HTML structure does not reflow — only the outer wrapper changes. Use a ResizeObserver or window resize listener to recalculate --ipod-scale.
  • The demo library auto-load: on DOMContentLoaded, check IndexedDB for existing tracks. If count === 0, attempt to fetch assets/music/track1.mp3 etc. If fetch fails (404), silently skip and leave library empty — show 'No songs. Drop MP3s here.' in the menu list.
  • Implement Playlists including On-The-Go: On-The-Go playlist is built by 'Add to On-The-Go' from context menu. It is persistent in localStorage. Standard playlists can be created (for demo: just show On-The-Go if library has tracks, else empty).
  • All text in the screen must use the device's simulated font size, NOT the browser's zoom level. Font sizes should be in px values relative to the device's rendered pixel size, set via CSS custom properties updated on scale change.
  • DO NOT reference any external URLs, CDNs, or Google Fonts. The file must work completely offline (aside from optional demo MP3/JPG assets).
